        # 如何获取分享链接
        
        
        
          在网易云音乐 App 打开单曲、歌单、专辑或歌手页 → 分享 → 复制链接。可将整段文案直接粘贴到输入框。
        
        

        
        # 字段说明
        
        
        
          单曲对齐 title / artist / album / cover / urls / lrc；歌单对齐
          id / title / cover / owner / tracks；专辑对齐
          id / name / artist / publishTime / tracks；歌手对齐
          id / name / alias / hotSongs / albums。
